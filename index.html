How to use this (5 min setup)

  1. Open Vial (web) next to this app. Go to Layout / Layers tab here, select each layer, and copy your labels over (click a key → edit). Do it once — it autosaves.
  2. Import your real layout (recommended): in Vial web do File → Save current layout to get a .vil file, then click ⬆ Import (.vil) up top and select it. All layers, MO/LT keys, tap-dances and shifted symbols come over automatically (transparent ▽ keys are filled from base).
  3. Keys that switch layers in Vial (MO(1), LOWER, RAISE) → set kind to Layer hold + target layer number. Thumbs are usually these.
  4. Go to Type, click the text, type. On a miss you get: expected “e”, you hit “r” (right index, KeyR) — adjust and repeat.
  5. Add your real combos in Shortcuts (e.g. ⌘+Shift+P agent palette, ⌘+Tab window switch). Use Practice mode to drill them with live detection.
  6. Split-keyboard technique: thumbs only for Space / Enter / layers, pinkies for outer columns + modifiers. The finger hint under the text tells you which finger should have pressed.

Corne reference (standard 42-key)

Top:    Tab Q W E R T | Y U I O P Bksp
Home:   Esc A S D F G | H J K L ; '
Bottom: Sft Z X C V B | N M , . / Sft
Thumbs (L→R): Ctrl  LOWER  Space | Bksp  Enter  RAISE/Alt
Lower (hold): numbers + symbols · Raise (hold): arrows + media · Adjust: RGB/reset

Boards are rendered from real keyboard definitions (matrix → physical positions, stagger included) — Corne 42 and Corne+ 46 rev4.1 (split_3x6_3_ex2) are built in. Got a different board? 📐 Load board definition with any QMK info.json (every Vial-supported board has one upstream), pick its layout, then Import your .vil — mapping is deterministic from there, no guessing.

Mirrored right half? Vial stores split right halves reversed on most firmwares — import auto-detects via your QWERTY rows. If letters still look backwards on the right, hit ⇄ Mirror right half in Layout.

Files: everything lives in this folder. Open index.html directly — no server, no build, works offline on Mac. Data autosaves to browser localStorage; use Export for backup.
